# MIAMI STATE

Open-World-Roleplay-Spiel für Roblox, angelehnt an die Atmosphäre einer Küstenstadt in Florida.
Eigene Inhalte, eigene Marke: keine fremden Assets, Karten oder Logos.

**Bereiche:** Police Department · Fire Department · EMS/Medical · Civilian/Life Roleplay

**Technik:** Roblox Studio · Luau · Trennung zwischen Server, Client und Shared · Claude über den offiziellen Roblox-Studio-MCP-Server
